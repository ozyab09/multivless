multivless

SOCKS5-шлюз, который держит все VLESS-серверы активными и выбирает исходящий узел отдельно для каждого TCP-соединения. Fail-closed, Web UI, XHTTP, история соединений и логи с флагами стран.

⚖️ Балансировка на соединение

adaptive, round-robin, least-latency и другие стратегии; health-check через сам туннель.

🔐 Fail-closed

Нет живых серверов — нет выхода. Direct существует только для torrent-bypass по явному флагу.

📊 Web UI

График трафика, история соединений, подписки с редактированием и частотами проверки.

🧾 Логи и DNS

Старт и завершение соединений, DNS-ответы с IP и флагом страны по geoip.dat.

🐳 Docker

Non-root, read-only rootfs, только localhost-порты, GOMEMLIMIT для небольших VPS.

🌐 XHTTP

Сборка sing-box-lx с with_xhttp; режим auto автоматически сводится к stream-one.

Быстрый старт

./scripts/fetch-geoip.sh           # флаги стран (необязательно)
export MULTIVLESS_API_TOKEN="$(openssl rand -hex 16)"
docker compose up --build -d
# UI: http://localhost:8080, SOCKS5: 127.0.0.1:1080
